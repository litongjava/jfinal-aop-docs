# jfinal-aop-docs

jfinal-aop 使用文档：拦截器、依赖注入、注解与实现原理。

- 文档站：https://jfinal-aop.io.nexus/
- 项目源码：https://github.com/litongjava/jfinal-aop
- 拆分自 [tio-boot-docs](https://github.com/litongjava/tio-boot-docs)

## 本地开发

```bash
pnpm install
pnpm docs:dev
```

## 构建

```bash
pnpm docs:check
pnpm docs:build
```

构建产物位于 `docs/.vuepress/dist`。
